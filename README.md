A short poem about agency, "Handoff": what it means to be handed the power to act, and to hand a choice back. The program writes the poem to `/output/entry.txt`, the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
